# NovaInsert v1.0.0

NovaInsert is a Windows productivity app for storing reusable inserts, commands, keyboard actions, and Library Insert Sets, then sending them to chosen destinations under user control.

## Downloads

### Recommended: Small ZIP

**NovaInsert-v1.0.0-win-x64-small.zip**

This is the preferred download for most users. It is small, but requires the Microsoft .NET 8 Desktop Runtime for Windows x64.

If NovaInsert does not start, install the .NET 8 Desktop Runtime and run NovaInsert again.

### Full ZIP

**NovaInsert-v1.0.0-win-x64-full.zip**

This larger package includes the required runtime. Use this if you do not want to install .NET separately.

## First run

1. Extract the ZIP.
2. Run `NovaInsert.exe`.
3. Start with the built-in README / Start Here guide.
4. For the first tutorial, turn on:
   - Enable sounds
   - Enable Nova dragon flight

These visual and sound cues help show where NovaInsert is sending an insert.
